## ลำดับที่แนะนำสำหรับ Request Indexing

1. หน้าแรก
2. หน้ารวมบริการ
3. หน้ารวมบทความ
4. หน้ารายละเอียดบริการทั้ง 6 หน้า
5. หน้าบทความทั้ง 6 หน้า

ก่อนกด `Request Indexing` ให้เลือก `Test Live URL` และตรวจว่าผลลัพธ์แสดงว่า URL สามารถให้ Google เข้าถึงได้

ไม่จำเป็นต้องส่ง `robots.txt` หรือ `sitemap.xml` ผ่าน URL Inspection โดยให้ส่ง `sitemap.xml` ผ่านเมนู **Sitemaps** ใน Google Search Console แทน

## คำค้นสำหรับตรวจสอบผลการจัดทำดัชนี

```text
site:c-electronics.online
site:c-electronics.online/services
site:c-electronics.online/articles
site:c-electronics.online inurl:services
site:c-electronics.online inurl:articles
```
